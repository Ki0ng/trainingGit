# Slides

This repository contains a Marp slide deck in `slides.md`.

## Preview While Editing

Install the Marp CLI if you do not already have it:

```powershell
npm install -g @marp-team/marp-cli
```

Run the live preview with watch mode:

```powershell
marp --preview --watch slides.md
```

Marp will open a browser preview and automatically refresh it when `slides.md`
changes.
